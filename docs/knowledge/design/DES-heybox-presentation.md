# Heybox Android 视觉迁移

## 范围与参考

按 FQ-009 迁移全部现有 presentation，不扩展业务。基准是用户提供的 Android APK
`com.max.xiaoheihe` 1.3.394 (1127)，使用新版首页。采样包含首页、正文/评论、搜索、个人页、
编辑器及其暗色版本。APK SHA-256：
`c6138fcd44d1343f8fe608ee983621490940e850ce54c674a9ee9972d7e4f5f7`。

复刻视觉语言，不把参考账号、私有内容、凭据或 APK 中的第三方商业素材纳入仓库。小白盒保留自己的
名称、内容与全部已有能力。没有对应参考样本的私信、Agent、记忆和追踪按同一套排版与控件规则适配，
不能宣称这些页面经过原版逐像素比对。

## 共享规则

`AppTheme` 是唯一主题所有者，保留 Flutter、Forui 0.24.2、Riverpod、GoRouter 与全局 overlay。
亮底/主字为 `#FFFFFF` / `#14191E`，暗底/主字为 `#101112` / `#E1E2E3`；次级表面与细分隔区别于
主表面。常用字号 12/14/16/18/20，字距 0。图像圆角 4，标签 2，常规控件不超过 8；不加浮卡阴影。

输入框采用低对比填充，聚焦与错误边框仍可见；正文编辑器使用无边框书写区域。图标来自既有
FLucideIcons，共享工具按钮提供语义与 tooltip。保留 touch/desktop variant、系统亮暗、键盘、
长文本与禁用动画适配。

## 页面结构

| 范围 | 结构 |
| --- | --- |
| 首页 | 左侧关注/推荐，推荐默认选中；移动右侧搜索/消息；通栏单列，12px 内容边距，6px 条目分隔 |
| Feed 图片 | 单图按宽度比例；两/三图三等分；更多图为左大右双图，显示总数；占位与失败保持几何 |
| 桌面 | 保留五项侧栏；Feed 阅读宽度 720，消息继续左右分栏；不复制原版未实现入口 |
| 移动导航 | 首页/搜索/发布/消息/我的；发布为独立加号；正文、编辑和线程页面隐藏底栏 |
| 详情 | 标题在作者之前；固定正文/评论入口；评论页省略正文，复用同一评论状态、排序和分页 |
| 互动栏 | 固定底部评论框与赞/藏/评论数；输入聚焦或有草稿时切为发送，失败保留输入 |
| 楼中楼 | 默认展示最多两条已有内嵌预览，展开才请求完整线程；回复对象仍挂到原顶级评论 |
| 搜索 | 紧凑搜索框、范围 Tab；结果按作者、标题、摘要、互动数排序，不捏造热搜和历史数据 |
| 个人 | 左头像右身份；横排统计、资料/记忆/追踪快捷入口；已有个性化开关和帖子/收藏 Tab |
| 编辑 | 直接书写标题和正文，下方标签与图片；保留发布、草稿、修改以及所有原有输入限制 |
| 消息 | 通栏会话、固定 Agent 线程；线程输入区只呈现现有可发送的文字/图片，未实现语音/视频不占位 |
| Agent | 紧凑标题与记忆/追踪入口；清历史与撤销授权进入更多菜单；保留授权披露、问答、来源卡和全部运行状态 |
| 管理/认证 | 记忆与追踪使用紧凑列表，修改/删除图标、追踪开关；登录注册与资料编辑统一字段样式 |

## 不变的边界

不改变 repository、notifier、SDK、鉴权、幂等、revision、游标或 SSE 契约。API 变更已获准，但本轮
没有发现视觉实现必须新增的字段，故不修改 API。标题仍为 1~120、正文 1~20000、最多 9 图和 10 标签，
不复制参考应用的 30 字标题约束。只读权限与错误恢复继续由现有业务状态决定。

实现与验收见 [IMP-heybox-presentation](../implementation/IMP-heybox-presentation.md)。
