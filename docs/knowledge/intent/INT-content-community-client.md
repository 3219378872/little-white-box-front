# 小白盒内容社区客户端

本意图已于 2026-08-13 获得人类明确批准，是本仓库产品方向与范围的正式语义上游。2026-08-29
按当前对话明确授权，将 Assistant 修订为消息页中的固定虚拟私信，而不是独立主导航或模式开关。

本仓库提供小白盒内容社区的 Flutter 客户端，使用户能在一致、可恢复的界面中发现、创建、发布、
讨论和收藏社区内容，维护公开资料，与其他用户进行一对一交流。

内容发现同时覆盖关注流、搜索和个性化推荐。客户端应保留请求、位置、来源、版本和实验等归因上下文，
只在真实可见或真实交互发生后形成可靠反馈，且反馈失败不能中断用户的主要操作。

内容社区是产品主体，普通搜索、推荐和社区操作独立于 Agent。Assistant 是认证用户在消息页里固定的
「小白盒 Agent」虚拟线程，用于澄清复杂需求、社区优先检索、必要时补充互联网资料并作有依据的综合回答，
不以独立通用陪伴为目标。本轮不定义首要用户群体。它不是机器人用户，也不属于普通用户私信。
用户必须先授权 Agent 才能发起任务。授权后，
客户端展示可列出、修改、删除和撤销的 MEMORY/USER 自然语言记忆，以及仅在助手线程投递的 Watch
条件追踪。Watch 命中以助手主动消息进入该虚拟线程并计入未读，不是独立命中收件箱，也不是系统
通知。来源只信任服务端验证的资料；一篇来源一张卡片展示相关原文摘录，可定位正文引用并访问原文，
不得把模型正文、私信或不可访问内容伪装成证据。检索型回答校验后完整展示，普通闲聊保留自然对话。
Assistant 只有一种通用 Agent 行为，不提供增强搜索/Agent 模式开关。

## 目标结果

- 匿名用户可以安全浏览公开内容、搜索和公开资料；认证后可以创作、互动、查看关注流、私信和使用
  Assistant。
- 同一业务能力在真实网关和仓库内 Mock 模式下经过相同的页面、状态与 repository 路径，便于开发和
  回归，同时明确 Mock 不能证明真实后端可用。
- 移动端和桌面端共享信息层级、主题语义和关键交互，在亮色、暗色以及 touch、desktop variant 下保持
  可用。
- 网络、流式响应或异步上报失败时，客户端给出可恢复状态，不重复权威写入，也不把失败解释成成功。
- 产品要求、工程设计、当前代码与验证结论可以沿稳定 ID 双向追溯，历史计划不会被误当成当前规则。

## 非目标

- 本仓库不决定后端服务拆分、存储、搜索引擎、推荐算法、模型、提示词或消息中间件。
- 当前客户端意图不包含管理后台、内容申诉、群聊、消息撤回/删除、自动评论/私信/购买、通用通知中心，
  独立 Watch 命中收件箱，以及把外部网络问答当作社区证据。
- Mock 数据、Widget 测试或本地 Web 构建不构成真实网关、生产鉴权、跨设备通知或线上推荐质量的证明。
- 知识整理本身不授权修改业务行为；已发现的契约偏离先进入实现与证据层，另行批准后再修复。
