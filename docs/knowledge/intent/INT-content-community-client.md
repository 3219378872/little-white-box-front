# 小白盒内容社区客户端

本意图已于 2026-08-13 获得人类明确批准，是本仓库产品方向与范围的正式语义上游。

本仓库提供小白盒内容社区的 Flutter 客户端，使用户能在一致、可恢复的界面中发现、创建、发布、
讨论和收藏社区内容，维护公开资料，与其他用户进行一对一交流。

内容发现同时覆盖关注流、搜索和个性化推荐。客户端应保留请求、位置、来源、版本和实验等归因上下文，
只在真实可见或真实交互发生后形成可靠反馈，且反馈失败不能中断用户的主要操作。

Assistant 用于理解用户查询、检索已发布的社区内容并组织可追溯回答。它不是通用互联网问答，也不应
把模型自身知识、私信或不可访问内容伪装成社区证据。

## 目标结果

- 匿名用户可以安全浏览公开内容、搜索和公开资料；认证后可以创作、互动、查看关注流、私信和使用
  Assistant。
- 同一业务能力在真实网关和仓库内 Mock 模式下经过相同的页面、状态与 repository 路径，便于开发和
  回归，同时明确 Mock 不能证明真实后端可用。
- 移动端和桌面端共享信息层级、主题语义和关键交互，在亮色、暗色以及 touch、desktop variant 下保持
  可用。
- 网络、流式响应或异步上报失败时，客户端给出可恢复状态，不重复权威写入，也不把失败解释成成功。
- 产品要求、工程设计、当前代码与验证结论可以沿稳定 ID 双向追溯，历史计划不会被误当成当前规则。

## 非目标

- 本仓库不决定后端服务拆分、存储、搜索引擎、推荐算法、模型、提示词或消息中间件。
- 当前客户端意图不包含管理后台、内容申诉、群聊、消息撤回/删除和外部网络问答。
- Mock 数据、Widget 测试或本地 Web 构建不构成真实网关、生产鉴权、跨设备通知或线上推荐质量的证明。
- 知识整理本身不授权修改业务行为；已发现的契约偏离先进入实现与证据层，另行批准后再修复。
